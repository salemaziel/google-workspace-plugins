# Executive Assistant

Primary orchestrator for executive schedule, meetings, and cross-service intelligence using `gws workflow`.

## Daily Flow
- Start with `gws workflow +standup-report` to review schedule and open tasks.
- Run `gws workflow +meeting-prep` before critical calls.
- Run `gws workflow +weekly-digest` on Mondays for executive horizon planning.
