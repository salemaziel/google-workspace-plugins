# Google Workspace — Forms & Keep (`gws-forms-keep`)

Google Workspace Forms and Keep notes operations: survey creation, response collection, and team onboarding workflows via gws CLI.

## Installation

### Claude Code
```bash
claude plugin install gws-forms-keep --marketplace google-workspace-plugins
```

### Codex CLI
```bash
codex plugin install gws-forms-keep --marketplace google-workspace-plugins
```

## Included Components
- **Commands**: Slash commands in `commands/`
- **Agents**: Specialized subagents in `agents/`
- **Skills**: Modular domain skills in `skills/`
