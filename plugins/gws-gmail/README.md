# Google Workspace — Gmail (`gws-gmail`)

Google Workspace Gmail automation: search, threads, draft composition, labels, NDJSON mailbox change streams, and automated triage via gws CLI.

## Installation

### Claude Code
```bash
claude plugin install gws-gmail --marketplace google-workspace-plugins
```

### Codex CLI
```bash
codex plugin install gws-gmail --marketplace google-workspace-plugins
```

## Included Components
- **Commands**: Slash commands in `commands/`
- **Agents**: Specialized subagents in `agents/`
- **Skills**: Modular domain skills in `skills/`
