# Google Suite CLI — Tasks (`gog-tasks`)

Google Tasks management, task list synchronization, due date tracking, and task completion with the gog CLI.

## Installation

### Claude Code
```bash
claude plugin install gog-tasks --marketplace google-workspace-plugins
```

### Codex CLI
```bash
codex plugin install gog-tasks --marketplace google-workspace-plugins
```

## Included Components
- **Commands**: Slash commands in `commands/`
- **Agents**: Specialized subagents in `agents/`
- **Skills**: Modular domain skills in `skills/`
