# Focus Time Reference & Parameters

### Flags & Options
- **Auto-Decline Modes**:
  - `gog`: `--auto-decline [all|new|none]`
  - `gws`: Handled via calendar settings or metadata extended properties.
- **Chat Status**:
  - `gog`: `--chat-status doNotDisturb` triggers Google Chat DND during the slot.
- **Transparency**:
  - Set to `opaque` to ensure the slot registers as **busy** in freebusy evaluations.
