# Google Suite CLI — Calendar (`gog-calendar`)

Google Calendar scheduling, agenda inspection, free/busy slot queries, and conflict-free meeting creation with the gog CLI.

## Installation

### Claude Code
```bash
claude plugin install gog-calendar --marketplace google-workspace-plugins
```

### Codex CLI
```bash
codex plugin install gog-calendar --marketplace google-workspace-plugins
```

## Included Components
- **Commands**: Slash commands in `commands/`
- **Agents**: Specialized subagents in `agents/`
- **Skills**: Modular domain skills in `skills/`
